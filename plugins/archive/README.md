# 사례 아카이브 for Claude

Claude 채팅·Cowork·Claude Code에서 희림 사내 건축 사례 아카이브(ArchDaily 프로젝트 약 5만 9천 건)를 검색하고 사진 카드로 봅니다.

- 명령: `/archive 목조 도서관` (Claude Code는 `/archive`, Cowork는 `/archive:archive`, 채팅에서는 그냥 말해도 됩니다)
- 설치(Claude Code): `claude plugin install archive --marketplace heeai-cloud/archive` · Claude 앱은 «마켓플레이스 추가»에 `heeai-cloud/archive`
- 연결: 커넥터 주소는 `https://dailyarchive.heeai.cloud/mcp`입니다. 연결할 때 heeai.cloud 로그인 화면이 뜹니다(희림 아이디, 사내 도구 대문과 같은 아이디).
- 할 수 있는 것: 사례 찾기(한국어·영어, 유형·국가·재료·연도·면적 조건), 사례 자세히 보기(사실·요약·사진 갤러리·ArchDaily 원문 링크), 비슷한 사례, 사진으로 찾기(아카이브 «이미지로 검색»과 같음), 북마크·컬렉션(아카이브 화면과 같은 목록)
- 사진으로 찾기: 카드 화면의 «사진 고르기»에 사진을 끌어 놓거나 붙여 넣습니다. Claude Code·Cowork에서는 Claude가 사진 파일을 직접 올립니다. 올린 사진은 검색에만 쓰고 1시간 뒤 지웁니다.
- 사진의 저작권은 원 사진가에게 있고 ArchDaily에서 가져왔습니다. 사내 참고용으로만 씁니다.
- 주고받는 곳: dailyarchive.heeai.cloud 한 곳입니다.
- `/archive`만 입력하면 검색창·예시·사진으로 찾기·내 북마크가 있는 첫 화면이 뜹니다(Claude 채팅·Cowork). Claude Code에서는 선택지 메뉴에서 고릅니다.
- 설치 안내: https://dailyarchive.heeai.cloud/claude/ · 사용법(질문 예와 받는 답): https://dailyarchive.heeai.cloud/claude/usage (둘 다 희림 아이디로 로그인해서 엽니다)
